# Web Blog – Travel Blog Application

## About the Project

Web Blog is a travel blog application developed as part of my studies. It allows users to create and manage blog posts about travel experiences and destinations.

Users can browse blog posts, view individual entries, and create, update, or delete posts. Each post includes information such as a title, description, image, and timestamp.

The application is built with Java and Spring Boot, using Thymeleaf to render the web pages.

## Features

* View all blog posts
* View individual blog posts
* Create new blog posts
* Update existing blog posts
* Delete blog posts
* Display post titles, descriptions, images, and timestamps
* Validate user input

## Technologies Used

* **Java 17** – application logic
* **Spring Boot** – application framework
* **Spring MVC** – web request handling
* **Thymeleaf** – server-side HTML rendering
* **Spring Data JPA** – database persistence
* **JDBC** – database connectivity
* **PostgreSQL** – relational database
* **H2 Database** – in-memory database support
* **Maven** – dependency management and build tool

## Getting Started

### Prerequisites

* Java 17 or later
* Git

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/sedina-imamovic/web-blog.git
   ```

2. Navigate to the project directory:

   ```bash
   cd web-blog
   ```

3. Run the application on Windows:

   ```bash
   mvnw.cmd spring-boot:run
   ```

   On macOS or Linux:

   ```bash
   ./mvnw spring-boot:run
   ```

   Database configuration may be required before starting the application.
